# ATM Machine / Bank System Simulator

A simple Python application that simulates basic banking and ATM transactions through the terminal.

---

## Features
* **Check Balance:** Instantly view your account balance.
* **Deposit Money:** Add funds securely using PIN verification.
* **Withdraw Money:** Withdraw cash with account balance validation.

---

##  How to Run
1. Make sure Python 3 is installed on your system.
2. Run the script using Terminal or VS Code:
   ```bash
   python "bank system"
